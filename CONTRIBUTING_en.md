# Contributing Guide

This project welcomes developers to experience and contribute. Before contributing to the community, refer to [cann-community](https://gitcode.com/cann/community) to understand the code of conduct, sign the CLA agreement, and learn the contribution process for source code repositories.

Developers need to pay attention to the following points when preparing local code and submitting PRs:

1. When submitting a PR, fill in the business background, purpose, and solution information according to the PR template.
2. If your modification is not a simple bug fix but involves new features, new interfaces, new configuration parameters, or modified code flows, discuss the solution through an Issue first to avoid your code being rejected. If you are unsure whether your modification qualifies as a "simple bug fix," you can also submit an Issue for solution discussion.

Developer contribution scenarios mainly include:

- Bug Fix

    If you discover certain bugs in this project and want to fix them, create an Issue to report and track the processing.

    Follow the [Submit Issue/Process Issue Task](https://gitcode.com/cann/community#提交Issue处理Issue任务) guide to create a `Bug-Report|缺陷反馈` type Issue to describe the bug. Then enter "/assign" or "/assign @yourself" in the comment box to assign the Issue to yourself for processing.

- Document Correction

    If you discover certain document description errors in this project, create an Issue to report and fix them.

    Follow the [Submit Issue/Process Issue Task](https://gitcode.com/cann/community#提交Issue处理Issue任务) guide to create a `Documentation|文档反馈` type Issue to point out the document problem. Then enter "/assign" or "/assign @yourself" in the comment box to assign the Issue to yourself to correct the document description.

- Help Solve Others' Issues

    If you have appropriate solutions for problems encountered by others in the community, post comments in the Issue to exchange ideas and help others solve problems and pain points, jointly optimizing usability.

    If the Issue requires code modification, enter "/assign" or "/assign @yourself" in the Issue comment box to assign the Issue to yourself and track the assistance in solving the problem.
