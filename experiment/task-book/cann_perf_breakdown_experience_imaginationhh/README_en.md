## Generation Method

Generated by the `cann-perf-breakdown` skill's Mode A full 5-step workflow:

```text
Step 1: analyze_kernels.py  → raw_ops*.json
Step 2: AI breakdown (raw_ops.compact.json + model source) → analysis_config.json
Step 3: Review validation loop  → analysis_config.json (final)
Step 4: generate_report.py   → breakdown_report.md / .html + ui-report/
Step 5: compute_metrics.py   → metrics
```

Input: NPU profiling output `kernel_details.csv` and DeepseekV3 model source code (`modeling_deepseek.py`).
